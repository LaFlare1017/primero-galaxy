A layer flips to closed before the page asks who owns the key — so the answer was “nobody”, and the press fell through.

Ordering that lives in the DOM's timing cannot be reviewed. It has to be asked about state.

The surface supplies behaviour, keyed by row id. That is all.

Add a row without behaviour and the menu can’t offer it. Add behaviour without a row and the sheet can’t show it.

The checks

Three questions one
declaration can’t ask itself.

Coherence

Does it agree with itself, in every state it can be in?

Can’t see: the page. It assumes the whole declaration is implemented.

Agreement

Do two declarations of one binding describe it the same way?

Can’t see: each surface’s own words — ids and labels stay out.

Coverage

Does pressing it actually do something visible?

Can’t see: whether the declaration is right. Only what it declares.

Coherence and agreement run in node, in milliseconds. Only coverage needs a browser.

One browser detail

The DOM’s timing is
part of your interface.

1 Esc reaches document in the capture phase.
2 The overlay library calls onEscapeKeyDown — and dismisses unless someone claims it.
3 Our handler on the input runs in the bubble phase. It runs after, so it never mattered.

The branch was dead from the day it was written. The fix was one prop — and then saying in the declaration that the two Escapes are one key in two states.

When a library owns an overlay, its dismissal path is an API.

The lesson that cost the most

The check that
failed to fail.

✅

Mutation applied: a binding’s keys emptied, so it does nothing.
The check passed.

Our coverage runner iterates a binding’s declared keys. With none declared, it walks straight past — no press, no exercise, no failure. The check that looked like it covered the case compared ids, which were still fine.

Now refused before a browser opens: “no declared binding may name zero keys, and be exercised by nobody.”

A check you have never seen fail is a claim, not a check.

Steal this

Five steps, in this order.

declarerows, gates, mounts, stacking — as data
readthe page dispatches from it; aria is built from it
enumeratethe states it can be in, and the invariant that filters them
pressevery binding, from a state where it is live, demanding a visible effect
mutatebreak it on purpose, until the check dies on the assertion it was aimed at

The step people skip is the last one — and it is the only one that tells you the check works.
